# Contributing

Thanks for looking. This repository is a **published mirror**: the code is
written, tested and reviewed in CloudWise's main repository, and each release
is exported here as a single commit. That keeps the open checks and the hosted
product on exactly the same code.

**Issues are very welcome.** The most useful report says:

- which finding was wrong (waste type, the resource, the saving shown), and
- why: the resource is in use, the price is off, the threshold doesn't fit
  your workload. Scrub account IDs and resource names you'd rather not share.

**Pull requests are not accepted**, because nothing merged here would survive
the next export. If you've found a fix, describe it in an issue; it will be
made upstream and ship in the next release, credited to you in the release
notes if you like.

For security problems, see [SECURITY.md](SECURITY.md) instead of opening an issue.
